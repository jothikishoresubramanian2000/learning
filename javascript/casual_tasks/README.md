# Casual Tasks

A flat, growing scratch folder — not part of the module curriculum, no topic teaching
attached. Random one-off tasks land here as `task1.js`, `task2.js`, ... whenever, in
no particular order. Nothing here is tracked against the roadmap or schedule.

## Difficulty levels

- **Simple** — completable in one file, one sitting. Straightforward, no real tricks.
- **Medium** — still usually one file, but tricky / a little complicated (an edge case,
  a combination of two concepts, something that makes you pause).
- **Hard** — a proper small project, closer to Phase-3 scale (may span more than one
  file/function, has real shape to it, not just a single function).

## Task format (all difficulty levels)

Every task gets a brief-to-detailed explanation (scaled by difficulty — simple tasks
get a short brief, hard tasks get fuller context) plus:
- **Expected Input**
- **Expected Output**

No hints regardless of difficulty — same rule as the module tasks (no method/keyword
named, no skeleton).

## Review convention

When checking a solution here: if it works but is more roundabout than a simpler
built-in method/approach would allow, call that simpler approach out explicitly and
explain it — even though this folder has no formal "teach the atom first" step.
